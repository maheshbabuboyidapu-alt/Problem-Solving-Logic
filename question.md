# Repository Workflow

This repository documents my problem-solving progression in Python.

For each problem:

- `question.md` — the problem statement for practice and community sharing.
- `01.py` — first-pass solution focused on understanding the requirements and implementing the core logic.
- `02.py` — improved solution with input validation, experiments, edge-case handling, PEP 8 structure, and documentation.

The goal is to show not only the final answer, but also how the solution improves over time.
